# Privacy

Yaze Media does not add analytics, advertising, tracking pixels, cookies, browser storage, a chatbot, or a contact-form processor to this website.

Contact links open the visitor's email client or GitHub. No message content is collected by the website itself.

The website is hosted by GitHub Pages. GitHub may process visitor information, including IP addresses, for service operation and security under the GitHub Privacy Statement.

Product screenshots use public or synthetic data and are reviewed to exclude private client information, local profile paths, credentials, databases, imports, and exports.
