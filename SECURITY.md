# Security policy

## Supported version

Only the current production version at <https://yazekt.github.io/> is supported.

## Reporting

Please report a security or privacy issue privately to `kirstentrimaley@gmail.com`. Do not publish credentials, personal information, private paths, or a working exploit in a public issue.

## Boundary

This is a static website with no accounts, server-side application, database, form processor, analytics, cookies, or content-management system. GitHub Pages serves the generated HTML, CSS, JavaScript, fonts, images, and resume PDF.
