# Homepage Surface Brief

- **Job and audience:** Give recruiters and product leads a fast, credible understanding of Yaze Media and Kirsten Trimaley, then let them inspect the work in depth.
- **Outcome and proof:** The primary action is View the work. Real screenshots, repository links, releases, and verification notes earn the positioning.
- **Direction:** Proof of Work. The first viewport is an editorial contact sheet with one live project proof and a rail for dlME, Nestform, Atlas Reach, and PinHarbor.
- **Boundary:** No generic agency services, unverified testimonials, private data, invented metrics, CMS, form storage, or old Lovable styling.
- **Interaction:** Content-first static HTML; React enhances only the project rail. Mobile keeps the same reading order and shows every project without requiring the rail.
- **Delivery:** Astro static output for the root GitHub Pages domain, WCAG 2.2 AA, responsive at 375/768/1024/1440, and fully readable with JavaScript or motion disabled.
