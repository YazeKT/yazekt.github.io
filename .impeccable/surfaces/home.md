# Homepage Surface Brief

- **Job and audience:** Give recruiters and product leads a fast, credible understanding of Yaze Media and Kirsten Trimaley, then let them inspect the work in depth.
- **Outcome and proof:** The primary action is View the work. Genuine screenshots, repository links, release evidence, and honest boundaries earn the positioning.
- **Direction:** The Yaze Product Atlas. A text-led cinematic workshop opens into a bright carved-paper landscape connected by a cobalt river. The first viewport has one small Yaze Media mark and no large Y-shaped hero.
- **Boundary:** No generic agency services, unverified testimonials, private data, invented metrics, fake application UI, CMS, form storage, or old Lovable styling. Generated artwork and real product evidence remain visibly separate.
- **Interaction:** Content-first static HTML. One progressively enhanced Three.js atlas scene supports the river transition, and React enhances only interactions that need state. Mobile keeps the same reading order without requiring the canvas.
- **Delivery:** Astro static output for the root GitHub Pages domain, WCAG 2.2 AA, responsive at 375/768/1024/1440, and fully readable with JavaScript or motion disabled.
- **Approved comp:** `design/review/homepage-yaze-product-atlas.png`.
